# iwad_runtime example

Runs `iwad_runtime` with an explicit IWAD path or web URL supplied by the app
user. The example does not bundle or download game data.

## Web

```sh
cd example
flutter run -d chrome
```

Enter a URL that the browser is allowed to fetch.

## Desktop

```sh
cd example
flutter run -d windows
```

Enter a local path to a legally obtained IWAD file.
